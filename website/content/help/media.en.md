## Index folders

Add multiple folders under **Footage & indexing**. Discovery includes subfolders and supports MP4, MOV, AVI, MKV, M4V, MTS, M2TS and WebM. Whether a file is actually readable also depends on its codec and condition.

Indexing stores metadata in a local library. Reindexing takes previously known files into account. Individual damaged files should not stop the entire import; check **Show errors** when needed.

## Check recording dates

Chronological order uses the stored recording date. Metadata inside a video is more informative than the date a file was copied to a drive. When reliable recording metadata is missing, the application has to fall back to less certain information.

Use **Check recording times** if a clip appears in the wrong period. Corrections are stored in the local index, leaving the original video unchanged. Enable the date range filter and check the included recordings before analysis.

## External drives and moved files

An unreachable folder remains in the index. Reconnect the drive and use **Check availability**. This verifies access; reindexing is needed to discover changes to folder contents.

Keep source files available during analysis, previews and export. If you move footage, stored references must point to accessible files again. Avoid deleting the index simply because a drive is disconnected.

## Work through large collections gradually

Start with a limited date range. Watch progress, cancel cleanly when needed and use **Resume** where available. Local analysis and Gemini analysis are separate steps; indexing alone uploads nothing to Gemini.
