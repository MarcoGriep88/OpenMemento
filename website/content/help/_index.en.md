OpenMemento helps turn many short family recordings into a chronological first cut. Choose your footage and movie length, review the suggested moments and render the movie on your computer.

**New here?** Start with [Your first movie](getting-started/). All you need initially is a small folder of videos. Later, semantic video analysis uses your own Gemini API key.

> This documentation describes the current development version. Automatic selection quality still needs validation with real family footage. Treat the proposed edit as a starting point to review yourself.
