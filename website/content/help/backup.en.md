## Create a library backup

Open **Backup / restore** and choose **Create new backup**. Store it somewhere appropriate, ideally keeping an additional copy on another drive.

The backup contains the **media index and analysis results**. It helps preserve paid analyses and corrections to indexed information.

## What is not included

**Original videos, movie projects, thumbnails and API keys are not backed up.** Back up your footage and movie projects separately. A library backup alone is not sufficient to migrate everything to another computer.

## Verify and restore a backup

1. Finish running jobs.
2. Choose **Choose and verify backup**.
3. Check the displayed information and source.
4. Only then choose **Restore verified backup** and confirm replacing the index.

The current library state is preserved separately before restoration. The selected backup then replaces the index; later index changes are retained only in that safety copy.

## Move to another computer

Transfer footage and project files separately, configure secure credential storage again and check stored source paths. Drive letters or user paths can differ on the new system. Test a small project before continuing with a large collection.
