## Choose an editing style

Under **Editing & music**, select a style and, where applicable, transition duration. The current project workflow starts with random transitions; choose a quieter template if you prefer simple cuts. Check the effect in the movie preview.

## Keep original audio

Background music is optional. Without a selected music file, the used segments retain their original audio where sources have a readable audio track. Speech, laughter and surrounding sounds can contribute more than music.

## Add background music

Enable background music and use **Choose music file** to select local audio. It is mixed quietly with the original audio and repeated when necessary. After exporting, check that conversations remain understandable and any repetition fits the movie.

## Prepare a Suno prompt

**Create Suno prompt from analyzed clips** prepares editable text from saved project information. Copy it into Suno if desired, create a song there and download it yourself. Then import the file into OpenMemento.

OpenMemento has no Suno API connection and does not download songs automatically. Check whether your chosen music can be used for the way you intend to share the movie.
